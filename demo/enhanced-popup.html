📦 Installation

Add the ChatUI widget to your website with enhanced security and composable widgets:

<!-- Enhanced ChatUI Widget --> <script id="chat-widget" src="../dist/chat-widget.js" data-server-url="https://your-chat-server.com" data-display="popup" data-position="bottom-right" data-color="#007bff" data-title="Chat with Support"> </script>

🔧 Configuration Options

  • data-server-url: Your chat server endpoint
  • data-display: Display mode ('popup' or 'fullpage')
  • data-position: Popup position ('bottom-right', 'bottom-left', 'top-right', 'top-left')
  • data-color: Primary color for the widget
  • data-title: Widget title
  • data-force-jsonp: Force JSONP fallback (true/false)

🔒 Enhanced Security Features

ChatUI now includes comprehensive security protections:

🛡️ XSS Protection

  • HTML sanitization for all user input
  • Script tag removal and escaping
  • JavaScript protocol filtering
  • Event handler removal

🔐 Input Validation

  • Type checking for message content
  • Length validation (max 10,000 characters)
  • Empty message prevention
  • Dangerous pattern detection

⚡ Rate Limiting

  • 1-second minimum message interval
  • Spam prevention
  • Automatic message throttling

🔒 Secure Storage

  • Session storage migration from localStorage
  • Session-scoped data for better security
  • Automatic cleanup on session end

🛡️ JSONP Security

  • Cryptographically secure callback names
  • Response structure validation
  • Callback manipulation prevention

🧩 Composable Widget System

📦 Widget Types

  • Text Widgets: Plain text and markdown support

  • Card Widgets: Styled content cards

🎨 Layout System
