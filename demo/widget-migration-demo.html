Migration Controls

Use these controls to see how different migration phases affect widget behavior:

Phase 1: Traditional Pattern (Backward Compatible) Phase 1

Each widget has its own embedded submit button. This is the current default behavior.

❌ Traditional (Deprecated)
✅ Composable (Recommended)
Phase 2: Migration Preparation Phase 2

Same behavior as Phase 1, but with warnings for deprecated patterns. Developers are encouraged to migrate.

⚠️ Traditional (Warnings)
✅ Composable (Recommended)
Phase 3: Composable Defaults Phase 3

Widgets default to no embedded buttons. Forms must explicitly request embedded buttons or use composable patterns.

❌ Traditional (Explicit Required)
✅ Composable (Default)
